Como Usar
Autenticação:


Primeiro faça login com POST /api/auth/login enviando credenciais
O sistema retornará um token JWT
Use este token no cabeçalho Authorization: Bearer {seu-token} para todas as requisições subsequentes
Consulta:


Use métodos GET com os parâmetros adequados na URL
Exemplo: GET /api/alunos/123 para obter detalhes do aluno com ID 123
Operações de Administrador:


Apenas contas com perfil ADMIN podem realizar operações de criação, atualização e exclusão
Use métodos POST para criar, PUT para atualizar e DELETE para excluir recursos
Documentação Detalhada:


Acesse a documentação Swagger em /swagger-ui.html para detalhes completos de cada endpoint, incluindo parâmetros necessários e esquemas de dados
Para mais detalhes sobre os parâmetros específicos de cada endpoint, consulte a documentação Swagger da API.
